# @arkitect/desktop

Optional local Electron workbench for Arkitect: repo connection, architecture policy, AI/MCP settings, and results.

Supported install for users is **mcp.json** after a local MCP server build. This app is not packaged as a Windows installer.

## Local dev

```powershell
pnpm dev:desktop
```

After `pnpm build`, from repo root:

```powershell
pnpm start:desktop
```
