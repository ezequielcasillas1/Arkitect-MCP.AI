Click a card to unlock its tools. Click again to lock.

Diagnosis is the entry point — scan the repo, then decide. Nothing refactors until you ask.

diagnose_repository

Analyze intake signals and return architecture, health, and intent before anything changes.

Example: “Run diagnose_repository on this repo — stabilize architecture before onboarding.”

get_last_diagnosis

Reuse the latest diagnosis payload without scanning again.

Example: “Show me the last diagnosis result.”

list_diagnosis_strategies

See how Arkitect continues healthy structure, reports drift, or defers a refactor.

Example: “What diagnosis strategies does Arkitect apply?”

suggest_requirement_tags

Suggest scope tags from the repo so diagnosis stays pointed at the right work.

Example: “Suggest requirement tags for this repo.”

Pattern intelligence — the catalog behind the algorithm. Same vocabulary as the architecture guide.

get_pattern_intelligence

Deep GoF data: intent, applicability, steps, pros/cons, and relations.

Example: “Get pattern intelligence for observer.”

recommend_patterns

Recommend patterns for this repo, with deferred options and an ADR summary.

Example: “Recommend patterns with complexityProfile balanced.”

list_design_principles

SOLID plus general OO principles Arkitect uses when scoring structure.

Example: “List the design principles Arkitect uses.”

list_design_patterns

The full catalog grouped by creational, structural, and behavioral families.

Example: “List design patterns available in the Arkitect catalog.”

Run verify and tests from the repo root — structured pass/fail the agent can act on.

verify_codebase

Full pipeline: lint, build, typecheck, test.

Example: “Verify the codebase at this path.”

run_tests

Unit and integration tests only — lighter than a full verify.

Example: “Run tests in this repo.”

run_test_suite

Scope a suite: unit, integration, or all.

Example: “Run the integration test suite.”

Report-only. Arkitect ranks techniques — it does not rewrite until you explicitly ask.

analyze_refactoring_opportunities

Rank Refactoring Guru techniques against structural smells. Reports only.

list_refactoring_techniques

The technique catalog grouped by category, with reference URLs.

Example: “List refactoring techniques for simplifying-conditionals.”
